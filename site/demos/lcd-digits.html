Every digit lights up on a 3-wide, 5-tall dot screen — X lit, . dark — with exactly one dark column between neighboring digits. Given a string of up to 100 digits, the program prints the five rows of the whole display. Play with the display here, then see the solution and a line-by-line trace in Row by Row.

1 ≤ n ≤ 100 each digit: 3×5 + 1 blank column output: 5 lines sample: 0123456789
