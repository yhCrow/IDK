# 3.4 Luogu P1044 — 栈 (Stack Permutations)

**Problem.** The numbers $1, 2, \dots, n$ are pushed onto a stack in order, and you may pop at any time. How many different output sequences are possible? ($1 \le n \le 18$)

## Key idea

Let $h[i]$ = the number of valid sequences for $i$ elements. Element 1 is pushed first and sits at the bottom until it is popped. That moment splits every sequence into two independent parts:

- **A** — what happens while 1 is still in the stack: a self-contained run on the next $j$ elements, $h[j]$ ways.
- **B** — what happens after 1 pops and the stack is empty: a fresh run on the remaining $i-1-j$ elements, $h[i-1-j]$ ways.

Different $j$ means 1 pops at a different moment, so no sequence is counted twice:

$$h[i] = \sum_{j=0}^{i-1} h[j]\cdot h[i-1-j], \qquad h[0] = h[1] = 1$$

These are the **Catalan numbers**: 1, 1, 2, 5, 14, 42, …

**Dual proof.** Ask which element $k$ is popped **last** instead. Elements $1..k-1$ must be fully done before $k$ is pushed ($h[k-1]$ ways), then $k+1..n$ run on top of $k$ ($h[n-k]$ ways). Summing over $k$ gives the same formula with $j = k-1$.

- Time: $O(n^2)$. $h[18] = 477\,638\,700$ still fits in `int`.

## Solution

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n;
    cin >> n;
    int h[20] = {0};
    h[0] = 1;
    h[1] = 1;
    for (int i = 2; i <= n; i++)
        for (int j = 0; j < i; j++)
            h[i] += h[j] * h[i-1-j];
    cout << h[n];
    return 0;
}
```

## Sample

```text
Input:  3
Output: 5
```

The five sequences are 123, 132, 213, 231 and 321.
