# 3.2 Luogu P1028 — 数的计算 (Half Prefix)

**Problem.** Start with a number $n$. You may put a new number in front of it, as long as the new number is **at most half** of the number currently at the front. Keep going as long as you like. How many different numbers can you build (including $n$ itself)?

## Key idea

Let $dp[i]$ = how many numbers can be built starting from $i$. From $i$ you either stop, or prefix some $j$ with $1 \le j \le \lfloor i/2 \rfloor$ and continue from $j$:

$$dp[i] = 1 + \sum_{j=1}^{\lfloor i/2 \rfloor} dp[j]$$

The code stores the "stop here" option as $dp[0] = 1$, so the sum can simply start at $j = 0$:

$$dp[i] = \sum_{j=0}^{\lfloor i/2 \rfloor} dp[j]$$

- Time: $O(n^2)$ in the worst case, fine for $n \le 1000$.
- Check: $dp[6] = dp[0] + dp[1] + dp[2] + dp[3] = 1 + 1 + 2 + 2 = 6$.

## Solution

```cpp
#include<bits/stdc++.h>

#define int long long
#define endl '\n'
#define float long double
#define fast ios_base::sync_with_stdio(0); cin.tie(0); cout.tie(0);
using namespace std;

signed main(){
    fast;
    int dp[1005]={1},n; // dp[0] silently becomes 1
    cin >> n;
    dp[1]=1,dp[2]=2;
    if(n==1 || n==2) cout << dp[n];
    else{
        for(int i=3;i<=n;i++){
            for(int j=0;j<=i/2;j++){
                dp[i]+=dp[j];
            }
        }
    cout << dp[n];
}
    return 0;
}
```

## Sample

```text
Input:  6
Output: 6
```

The six numbers are 6, 16, 26, 126, 36 and 136.
