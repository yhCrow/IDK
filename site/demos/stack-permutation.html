Proof: why h[i] = ∑ h[j]·h[i−1−j]

Element 1 is always pushed first — there's nothing else to push yet. It sits at the bottom of the stack until, at some point, it finally gets popped. That one moment splits every sequence into two independent pieces: push(1), then A — whatever happens while 1 is still buried underneath — then pop(1), then B — whatever happens after the stack is empty again.

A can't touch 1 (it's stuck on the bottom), so A is just a smaller, self-contained stack run on the next j elements: h[j] ways. The instant 1 pops, the stack is empty, so B is a fresh, independent run on the remaining i−1−j elements: h[i−1−j] ways. Different j means 1 pops at a different moment, so these groups never overlap — summing them counts every sequence exactly once.

The dual proof: condition on who pops last

Textbooks often run this the other way round (入管 = enter the tube = push, 出管 = exit the tube = pop): instead of asking "when does the first ball leave," ask "which ball leaves last?" Call that ball k — it was the k-th one pushed.

If ball k is popped dead last, the stack must be completely empty right before k is even pushed — otherwise whatever's still sitting under where k would go could only come out after k, contradicting "k is last." So balls 1..k−1 must already be fully pushed and popped by then: a self-contained run, h[k−1] ways. Then k goes on the stack, balls k+1..n run their own self-contained sequence on top of it (h[n−k] ways), and only then does k finally pop:

Exactly one ball is last, so summing over every possible k counts each sequence once: h[n] = ∑k=1..n h[k−1]·h[n−k] — substitute j = k−1 and it's the identical formula as before.
