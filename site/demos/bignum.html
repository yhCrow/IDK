高精度运算：逐位处理与进位传播

当整数超出 long long 的范围（约 9.2×10¹⁸）时， 需要用数组按位模拟竖式运算 —— 这就是「高精度」（bignum）。下面四个演示分别对应 bignum.cpp 中的 add()、 sub()、 mul() 与 divInt() 函数，逐行执行代码、逐步展示进位/借位/余数是如何产生和传播的，右侧同步显示每个变量当前的值。

① 高精度加法 — 逐位相加 + 进位传播

从最低位（个位）开始，每一位把两个加数的对应数字与上一位传来的进位相加， 结果对 10 取模作为当前位，商作为新的进位传给下一位。对应代码： s = x + y + carry; c[i] = s % 10; carry = s / 10;

② 高精度乘法 — 累加到 c[i+j]，最后统一进位

竖式乘法把每一对数字 a[i]·b[j] 累加到结果数组的第 i+j 位（「桶」）， 所有乘积都先不进位地堆在桶里，直到双重循环结束，才做一次从低位到高位的统一进位。 这正是它比逐次做加法更快的关键。

③ 高精度减法 — 逐位相减 + 借位传播

先用 cmpAbs 比较两数绝对值大小，保证从大数里减小数；再从最低位开始相减， 不够减就向被减数当前位先扣 1（s += 10; borrow = 1;），差值留到本位， 借位传给下一位。对应代码： s = x - y; if (s < 0) { s += 10; borrow = 1; }

④ 高精度除法（除以低精度）— 从高位到低位试除

和加减法方向相反：除法从最高位开始往低位走。把当前累积的余数左移一位（乘 10） 再接上这一位的数字，得到 cur；cur 除以除数 m 的商就是这一位的答案， 余数则带去参与下一位的计算——是一种反方向的「借位」式传播。对应代码： cur = r*10 + a.d[i]; c.d[i] = cur/m; r = cur%m;
