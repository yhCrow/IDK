# 2.1 Prefix Sums & Difference Arrays

## 1D prefix sums

**Problem:** answer many "sum of $a[l..r]$" queries quickly.

Build $P[i] = a[1] + a[2] + \dots + a[i]$ with $P[0] = 0$. Then:

$$\text{sum}(l, r) = P[r] - P[l-1]$$

Building takes $O(n)$ and each query takes $O(1)$, instead of $O(n)$ per query.

```cpp
int n, q;
cin >> n >> q;
vector<long long> P(n + 1, 0);
for (int i = 1; i <= n; i++) {
    long long x; cin >> x;
    P[i] = P[i - 1] + x;
}
while (q--) {
    int l, r; cin >> l >> r;
    cout << P[r] - P[l - 1] << '\n';
}
```

## 2D prefix sums

$P[i][j]$ = sum of the rectangle from $(1,1)$ to $(i,j)$.

$$P[i][j] = a[i][j] + P[i-1][j] + P[i][j-1] - P[i-1][j-1]$$

Sum of the rectangle $(x_1, y_1)$ to $(x_2, y_2)$:

$$P[x_2][y_2] - P[x_1-1][y_2] - P[x_2][y_1-1] + P[x_1-1][y_1-1]$$

The last term is **added back** because it was subtracted twice (inclusion–exclusion).

## Difference arrays

**Problem:** do many "add $v$ to every element of $a[l..r]$" updates, then read the final array.

Let $D[i] = a[i] - a[i-1]$. A range update touches only **two** cells:

$$D[l] \mathrel{+}= v \qquad D[r+1] \mathrel{-}= v$$

Taking the prefix sum of $D$ at the end gives back the final array. That is $O(1)$ per update and $O(n)$ at the end.

```cpp
vector<long long> D(n + 2, 0);
while (m--) {
    int l, r; long long v;
    cin >> l >> r >> v;
    D[l] += v;
    D[r + 1] -= v;
}
long long cur = 0;
for (int i = 1; i <= n; i++) {
    cur += D[i];          // cur is now the final a[i]
    cout << cur << ' ';
}
```

> **Remember:** Prefix sums and difference arrays undo each other — the prefix sum of $D$ is $a$, and the difference of $P$ is $a$.
