# Physics — Formula Sheet <span class="zh">公式表</span>

## Kinematics <span class="zh">运动学</span>

| Formula | Meaning |
|---|---|
| $v = u + at$ | Final velocity |
| $s = ut + \tfrac{1}{2}at^2$ | Displacement |
| $v^2 = u^2 + 2as$ | Velocity without time |
| $s = \tfrac{1}{2}(u+v)t$ | Displacement without acceleration |
| $a = \dfrac{v-u}{t}$ | Acceleration |

## Dynamics <span class="zh">动力学</span>

| Formula | Meaning |
|---|---|
| $F = ma$ | Newton's second law |
| $F = \dfrac{\Delta p}{\Delta t}$ | Force as rate of change of momentum |
| $W = mg$ | Weight |
| $p = mv$ | Momentum |
| $F\Delta t = \Delta p$ | Impulse |
| $f = \mu N$ | Kinetic friction |
| $m_1u_1 + m_2u_2 = m_1v_1 + m_2v_2$ | Conservation of momentum |

## Energy <span class="zh">能量</span>

| Formula | Meaning |
|---|---|
| $W = Fs\cos\theta$ | Work done |
| $E_k = \tfrac{1}{2}mv^2$ | Kinetic energy |
| $E_p = mgh$ | Gravitational potential energy |
| $P = \dfrac{W}{t} = Fv$ | Power |
| $\text{efficiency} = \dfrac{\text{useful output}}{\text{total input}} \times 100\%$ | Efficiency |

## Electricity <span class="zh">电学</span>

| Formula | Meaning |
|---|---|
| $I = \dfrac{Q}{t}$ | Current |
| $V = \dfrac{W}{Q}$ | Potential difference |
| $V = IR$ | Ohm's law |
| $R = \dfrac{\rho L}{A}$ | Resistivity |
| $R_s = R_1 + R_2 + \dots$ | Series resistance |
| $\dfrac{1}{R_p} = \dfrac{1}{R_1} + \dfrac{1}{R_2} + \dots$ | Parallel resistance |
| $P = IV = I^2R = \dfrac{V^2}{R}$ | Electrical power |
| $E = I(R + r)$ | E.m.f. and internal resistance |
