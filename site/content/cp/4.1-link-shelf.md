# 4.1 Link Shelf

Judges to practise on, guides to learn from, references to check syntax, and tools that speed up a contest. **★ Start** marks a good first stop for beginners.

## Online judges

Where you solve problems and take part in rated contests.

| Site | What it is |
|---|---|
| [Codeforces](https://codeforces.com) ★ Start | Weekly rated rounds, huge problemset with tags and ratings, active blog. |
| [AtCoder](https://atcoder.jp) ★ Start | Clean, well-tested problems. ABC for beginners, ARC and AGC for harder ones. |
| [CSES Problem Set](https://cses.fi/problemset/) ★ Start | 300+ classic problems grouped by topic. A standard checklist. |
| [USACO](https://usaco.org) | USA olympiad with Bronze to Platinum divisions and past contests. |
| [Luogu 洛谷](https://www.luogu.com.cn) | Large Chinese judge with OI problems, solutions and training lists. |
| [oj.uz](https://oj.uz) | Archive of olympiad problems: IOI, APIO, JOI, BOI, CEOI and more. |
| [QOJ](https://qoj.ac) | Mirror of many ICPC and OI contests, often used for gym practice. |
| [LibreOJ](https://loj.ac) | Open-source judge with OI and template problems. |
| [Library Checker](https://judge.yosupo.jp) | Test your data structure and algorithm templates against strong data. |
| [Kattis](https://open.kattis.com) | ICPC-style problems from many regional contests. |
| [CodeChef](https://www.codechef.com) | Weekly Starters contests and a long problem archive. |
| [SPOJ](https://www.spoj.com) | Old but deep archive of classic problems. |
| [LeetCode](https://leetcode.com) | Interview-style problems and weekly contests. |
| [Project Euler](https://projecteuler.net) | Mathematical problems that reward clever number theory. |

## Starter template

Compile with `g++ -std=c++20 -O2 -Wall main.cpp`.

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

void solve() {
    int n; cin >> n;
    vector<ll> a(n);
    for (auto &x : a) cin >> x;
    // your solution here
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t = 1;
    cin >> t;            // remove for single-test problems
    while (t--) solve();
}
```
