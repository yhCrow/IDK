# Luogu P5730 — 显示屏 (LCD Digits)

**Problem.** Given a string of up to 100 digits, draw it on a dot display. Each digit is 3 columns wide and 5 rows tall (`X` = lit, `.` = dark). One dark column separates neighbouring digits. Print the five rows.

| Limit | Value |
|---|---|
| $n$ | $1 \le n \le 100$ |
| Each digit | $3 \times 5$, plus 1 blank column between digits |
| Output | 5 lines |

## Key idea

The output is printed **one screen row at a time**, not one digit at a time. So store the ten glyphs in a table `pat[digit][row]`. For each row `r`, sweep across every digit and print `pat[s[i]-'0'][r]`, with a `'.'` before every digit except the first.

- Time: $O(5n)$ — each of the 5 rows visits all $n$ digits.
- The table is the whole trick: once the glyphs are data, the printing is two nested loops.

## Solution

```cpp
#include<bits/stdc++.h>

#define int long long
#define endl '\n'
#define double long double
#define fast ios_base::sync_with_stdio(0); cin.tie(0); cout.tie(0);
using namespace std;

string pat[10][5] = {
    {"XXX","X.X","X.X","X.X","XXX"}, // 0
    {"..X","..X","..X","..X","..X"}, // 1
    {"XXX","..X","XXX","X..","XXX"}, // 2
    {"XXX","..X","XXX","..X","XXX"}, // 3
    {"X.X","X.X","XXX","..X","..X"}, // 4
    {"XXX","X..","XXX","..X","XXX"}, // 5
    {"XXX","X..","XXX","X.X","XXX"}, // 6
    {"XXX","..X","..X","..X","..X"}, // 7
    {"XXX","X.X","XXX","X.X","XXX"}, // 8
    {"XXX","X.X","XXX","..X","XXX"}, // 9
};

signed main(){
    fast;
    int n;
    string s;
    cin >> n >> s;

    for(int r=0;r<5;r++){
        for(int i=0;i<n;i++){
            if(i) cout << '.';
            cout << pat[s[i]-'0'][r];
        }
        cout << endl;
    }

    return 0;
}
```

```text
Input:
10
0123456789

Output:

X.X...X...X...X.X.X.X...X.....X.X.X.X.X
X.X...X.XXX.XXX.XXX.XXX.XXX...X.XXX.XXX
X.X...X.X.....X...X...X.X.X...X.X.X...X
XXX...X.XXX.XXX...X.XXX.XXX...X.XXX.XXX
```

> **Tip:** When the output is a picture, first work out **the order the characters are printed in**. Here it is row by row across the whole screen, so the loops are "row outside, digit inside".
