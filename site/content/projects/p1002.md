# Luogu P1002 — 过河卒 (River Pawn)

**Problem.** A pawn walks from $(0,0)$ to $(n,m)$ on a grid, moving only **right** or **down**. A horse stands at $(h_x, h_y)$. The pawn may not step on the horse's square or any of the 8 squares the horse can jump to. Count the paths.

| Limit | Value |
|---|---|
| $n, m$ | $\le 20$ |
| Answer | Can exceed `int` — use `long long` |

## Key idea

Every square is reached either from above or from the left, so

$$d[x][y] = d[x-1][y] + d[x][y-1]$$

with $d[0][0] = 1$ and $d = 0$ on every blocked square. The first row and first column each have only one way in.

The 8 knight moves are the offsets $(\pm1, \pm2)$ and $(\pm2, \pm1)$. Mark only those that land **inside** the board.

- Time: $O(nm)$.

## Solution

```cpp
#include<bits/stdc++.h>

#define int long long
#define endl '\n'
#define fast ios_base::sync_with_stdio(0); cin.tie(0); cout.tie(0);
using namespace std;

int d[25][25];
bool blocked[25][25];
int dx[8] = {-2,-2,-1,-1,1,1,2,2};
int dy[8] = {-1,1,-2,2,-2,2,-1,1};

signed main(){
    fast;
    int n, m, hx, hy;
    cin >> n >> m >> hx >> hy;

    // the horse's own square and its 8 knight moves are off limits
    blocked[hx][hy] = true;
    for(int i=0;i<8;i++){
        int x = hx + dx[i], y = hy + dy[i];
        if(x >= 0 && x <= n && y >= 0 && y <= m) blocked[x][y] = true;
    }

    d[0][0] = blocked[0][0] ? 0 : 1;
    for(int x=0;x<=n;x++){
        for(int y=0;y<=m;y++){
            if(x==0 && y==0) continue;
            if(blocked[x][y]) d[x][y] = 0;
            else if(x==0) d[x][y] = d[x][y-1];
            else if(y==0) d[x][y] = d[x-1][y];
            else d[x][y] = d[x-1][y] + d[x][y-1];
        }
    }
    cout << d[n][m] << endl;

    return 0;
}
```

## Sample

```text
Input:  6 6 3 3
Output: 6
```

> **Tip:** Two classic wrong answers: using `int` (the count overflows on a $20 \times 20$ board), and forgetting that the horse's **own** square is blocked too.
